## BR-001: Core Wedding Project Profile Establishment

# Description
The business requires the mandatory collection of fundamental wedding details, including client identity, primary dates, location, core venues, and expected scale, at the initiation of any new project.

# Stakeholder Need
Wedding Planners need a standardized baseline of client and event information to accurately scope, resource, and budget the project.

# Business Rationale
Establishing strict baseline data parameters prevents downstream operational failures caused by ambiguous or missing foundational project information, ensuring all subsequent planning is aligned with the correct client, location, and scale.

Reduces time spent chasing missing information by 100% at project kickoff and ensures accurate initial resource allocation.

# Business Impact
Area:
Project Onboarding (Standardizes the intake process, directly influencing how quickly a planning team can transition from onboarding to active execution.)
Affected Stakeholders:
Wedding Planners, Banquet Teams

# Success Metrics

Project Initiation Completeness (Target 100%) - Percentage of new projects possessing all mandatory core profile details at inception

# Assumptions
Clients have finalized basic scale and location parameters before officially initiating the planning process.

# Dependencies

Business Process: Requires an established client onboarding process that naturally surfaces these key details.

# Constraints

Business: Core fields cannot be bypassed, ensuring absolute data integrity for organizational reporting.

## BR-2901: Regulated Escrow and Split Payment Routing

# Description

The business requires the integration of Cashfree's Virtual Bank Accounts and Virtual UPI IDs to facilitate automated escrow and split payouts. High-value transactions must default to RTGS, IMPS, or NEFT, while lower-value transactions utilize UPI.

# Stakeholder Need

Vendors require absolute assurance of payment upon delivery, and planners need to automate the splitting of client funds directly to vendors without routing everything manually through their own operational accounts.

# Business Rationale

Manual fund routing is slow, prone to clerical errors, and creates severe cash-flow bottlenecks. An integrated escrow system builds immense trust within the vendor network, incentivizing platform adoption, while Cashfree automation handles the ledger reconciliation instantly.

# Business Impact

Area: Treasury & Network Adoption (Radically reduces planner accounting overhead and serves as the primary hook for vendor onboarding.)

Affected Stakeholders: Wedding Planners, Vendors, Clients

# Success Metrics

Automated Reconciliation Rate (Target 100%) - Percentage of escrow-routed payments requiring zero manual ledger entry.

# Assumptions

Vendors will complete necessary KYC to receive funds via the Cashfree split network.

# Dependencies

External System: Relies on Cashfree API uptime and accurate webhook delivery.

# Constraints

Operational: To ensure transaction security and maintain user context, all UPI payments must present the QR code natively within the application; external web browser redirection is strictly prohibited.
